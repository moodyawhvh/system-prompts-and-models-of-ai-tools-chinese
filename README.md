## 📖 项目简介

本项目是 GitHub 上星标超过 14 万的知名开源合集 [system-prompts-and-models-of-ai-tools](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools) 的中文翻译介绍版。原项目系统收录了 Cursor、Claude Code、Devin AI、v0、Lovable、Windsurf、Replit、Trae、Manus、Kiro、Junie 等数十款主流 AI 编程工具与 AI 智能体的完整系统提示词、内部工具定义与模型信息,是研究提示词工程与 AI 产品设计的珍贵资料库。本仓库提供中文导读与文档翻译,帮助中文开发者快速了解项目结构与内容,完整提示词原文请以原项目为准。

## ✨ 主要特性

- **覆盖面广**:收录 30+ 款 AI 编程工具与智能体的系统提示词,包括 Cursor、Claude Code、Devin AI、Windsurf、v0、Lovable、Replit、Same.dev、Trae、Augment Code、Kiro、Junie、Qoder、CodeBuddy、NotionAI、Perplexity、Manus、Xcode、VSCode Agent、Z.ai Code 等
- **内容完整**:不仅有系统提示词,还包含内部工具(Internal Tools)定义与 AI 模型信息
- **开源补充**:额外收录 Amp、Anthropic、Emergent、Google、dia、Poke、Comet Assistant、Traycer AI、Leap.new、Orchids.app、Cluely 等开源或新锐产品的提示词
- **按工具分目录**:每个工具独立文件夹,结构清晰,便于检索与对比研究
- **持续更新**:作者长期跟进新工具与新版本,原项目更新频繁
- **社区活跃**:拥有 LeaksLab Discord 社区,可参与讨论与反馈
- **提示词工程范本**:适合用于学习提示词结构设计、工具调用编排、安全防护写法
- **GPL-3.0 开源许可**:遵循原项目开源协议

## 🚀 快速开始

1. 访问原项目仓库:https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools
2. 将原项目克隆到本地:

   ```bash
   git clone https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools.git
   ```

3. 进入仓库目录,浏览按工具划分的文件夹(如 `Cursor Prompts`、`Devin AI`、`v0 Prompts and Tools` 等):

   ```bash
   cd system-prompts-and-models-of-ai-tools
   ls
   ```

4. 打开感兴趣的工具目录,阅读其中的系统提示词与工具定义文件
5. 结合本仓库 [README.zh-CN.md](README.zh-CN.md) 的中文导读,快速定位所需内容
6. 对比不同工具的提示词写法,学习提示词工程与智能体设计模式
