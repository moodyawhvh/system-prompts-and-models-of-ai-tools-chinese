## 🛠️ 使用建议

1. **学习提示词工程**:对比不同产品如何定义角色、约束输出、编排工具调用
2. **研究智能体架构**:参考 Devin、Manus、Replit Agent 等的工具定义与状态管理写法
3. **加固自家产品**:了解常见泄露路径,针对性做好提示词防护
4. **检索技巧**:按工具目录定位,再结合关键词(如 `tool`、`rules`、`guardrail`)全文搜索
